# Business Glossary

| Term | Definition | Source |
|---|---|---|
| Account current balance | The monetary balance currently carried by a credit-card account. It is the amount evaluated for payment eligibility and the amount settled by the online bill-payment process. | `00.phase-1-input/cpy/CVACT01Y.cpy`, lines 4-16; `00.phase-1-input/cbl/COBIL00C.cbl`, lines 193-205 and 224-235 |
| Online bill payment | A payment transaction created after confirmation to settle an eligible account's full current balance. The transaction is labelled `BILL PAYMENT - ONLINE`, has type code `02`, category code `2`, and is recorded as a bill payment. | `00.phase-1-input/cbl/COBIL00C.cbl`, lines 208-235 |
| Payment eligibility | The business condition that an account must have a current balance greater than zero before it can be paid online. | `00.phase-1-input/cbl/COBIL00C.cbl`, lines 197-205 |
| Transaction | A financial record containing its identifier, type, category, source, description, signed amount, merchant information, associated card number, original timestamp, and processing timestamp. | `00.phase-1-input/cpy/CVTRA05Y.cpy`, lines 4-18 |
| Transaction amount | The signed monetary value of a transaction. For an online bill payment, it equals the account's entire current balance at payment time. | `00.phase-1-input/cpy/CVTRA05Y.cpy`, lines 4-18; `00.phase-1-input/cbl/COBIL00C.cbl`, lines 224-235 |
| Transaction type | A two-character code that classifies a transaction. The online bill-payment flow assigns type code `02`. | `00.phase-1-input/cpy/CVTRA05Y.cpy`, lines 4-10; `00.phase-1-input/cbl/COBIL00C.cbl`, lines 219-223 |
| Transaction category | A numeric classification paired with a transaction type. The online bill-payment flow assigns category code `2`. | `00.phase-1-input/cpy/CVTRA04Y.cpy`, lines 4-9; `00.phase-1-input/cbl/COBIL00C.cbl`, lines 219-223 |
| Transaction processing date | The date on which a transaction is processed. Report generation uses this date to select transactions that fall within the requested reporting period. | `00.phase-1-input/cpy/CVTRA05Y.cpy`, lines 15-17; `00.phase-1-input/proc/TRANREPT.prc`, lines 39-46 |
| Monthly transaction report | A report option that selects transactions with processing dates from the first through the last day of the current calendar month. | `00.phase-1-input/cbl/CORPT00C.cbl`, lines 212-238 |
| Yearly transaction report | A report option that selects transactions with processing dates from January 1 through December 31 of the current calendar year. | `00.phase-1-input/cbl/CORPT00C.cbl`, lines 239-255 |
| Custom transaction report | A report option that uses the supplied start and end dates as the transaction-processing-date range. The code validates supplied dates but does not impose an additional business range constraint. | `00.phase-1-input/cbl/CORPT00C.cbl`, lines 256-436; `00.phase-1-input/proc/TRANREPT.prc`, lines 41-46 |
| Credit limit | The monetary credit limit maintained for an account. The reviewed source stores and displays this value but does not apply it in an approval threshold or calculation. | `00.phase-1-input/cpy/CVACT01Y.cpy`, lines 4-16 |
| Cash credit limit | The monetary limit maintained for cash credit on an account. The reviewed source stores and displays this value but does not apply it in an approval threshold or calculation. | `00.phase-1-input/cpy/CVACT01Y.cpy`, lines 4-16 |
| Current-cycle credit | The account-level amount recorded as current-cycle credit. The reviewed source stores and displays this value without calculating or applying it to a decision. | `00.phase-1-input/cpy/CVACT01Y.cpy`, lines 4-16 |
| Current-cycle debit | The account-level amount recorded as current-cycle debit. The reviewed source stores and displays this value without calculating or applying it to a decision. | `00.phase-1-input/cpy/CVACT01Y.cpy`, lines 4-16 |
| Transaction category balance | A signed balance identified by account, transaction type, and transaction category. It is defined in the copybook but is not calculated or used in a consequential business decision by the reviewed COBOL programs. | `00.phase-1-input/cpy/CVTRA01Y.cpy`, lines 4-10 |
